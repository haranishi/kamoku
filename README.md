# kamoku

日本の個人事業主が、自分のパソコンの中だけで帳簿をつけ、税理士にも渡せる。そんな会計ソフトを、Rustで作るOSSです。いまあるのは設計文書と、台帳の核になる2つのライブラリだけで、画面のあるアプリはまだありません。名前の「kamoku」は「科目」のことで、商標の検索（J-PlatPat）が済むまでは変わる可能性があります。

> **English:** Local-first double-entry bookkeeping for Japanese sole proprietors, written in Rust. Pre-alpha: design documents and two core libraries only; no app yet. Documentation is in Japanese.

## いま動くもの、動かないもの

| 部品 | 状態 | 内容 |
|---|---|---|
| `kamoku-ledger` | 動く（試験あり） | 仕訳を追記だけで管理し、訂正の履歴をハッシュでつないで改ざんを検知する台帳 |
| `kamoku-jp-tax` | 動く（税理士の確認前） | 消費税の税率、端数処理、インボイスの経過措置を、根拠つきの表で持つ計算 |
| 取込・画面・書き出し | 未着手 | [ロードマップ](docs/roadmap.md)の Phase 1 以降 |

## めざすこと

データを手元に持つこと、キーボードだけで月の記帳を終えること、弥生形式のCSVで税理士に渡すこと。この3つを、青色申告の個人事業主に絞ってめざします。速さの目標は「画面操作を50ミリ秒以内」ですが、まだ測っていません。アプリができた段階で、測定方法と結果を公開します。

freeeやマネーフォワードの代わりを名乗るものではありません。口座の自動連携や申告書の自動作成のように、クラウド会計が得意なことは作りません。理由は[コンセプト](docs/concept.md)に書きました。

## 作らないもの

- 銀行口座・カードの自動連携（CSVの取込だけ）
- e-Taxでの申告書の送信
- 給与計算、請求書の発行
- クラウド同期と、サーバーで動かす版

見直す条件は、[設計](docs/architecture.md)の「やらないと決めたこと」にあります。

## 免責

これは税務の助言ではありません。日本文書情報マネジメント協会（JIIMA）の電子帳簿ソフト認証は取っておらず、電子帳簿保存法に「対応済み」とは言いません。自動で出す科目や税区分は参考値です。全文は[DISCLAIMER.md](DISCLAIMER.md)にあります。
