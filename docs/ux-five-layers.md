# 画面は「次にやること」から始め、確認して確定する流れを中心に作る（UXの5階層）

最初のアプリ（v0.1-alpha）の画面を作る前に、戦略から表層までを一度通した記録です。通した結果、設計が12か所変わりました（末尾）。画面ごとの仕様は[spec/](spec/stories-record.md)にあります。

## 戦略: 月の記帳を、手を止めずに終わらせる

使い手は、月に50〜200件の取引がある青色申告の個人事業主です。目的は、月の記帳を手を止めずに終えることです。マウスに持ち替える一回一回が、記帳を面倒にしている最大の原因だと仮定しています（作者の実感で、調べてはいません）。

成功の基準は、100件を取り込んでから確定するまで、キーボードだけで5分以内です。この数字も仮説で、最初に作者自身の入力で測ります。

もう1つの基準は、初めて開いた人が3分で記帳を始められることです。参加者のために、本物の帳簿に触れないデモを用意し、15分で画面を見られる状態にします。

## 要件: 13の物語

利用者の物語は13あり、条件には番号を付けました（[記帳](spec/stories-record.md)、[確認・共有・参加](spec/stories-review.md)）。柱は4つです。

- 取引を登録する（収入・支出・振替、家事按分）
- 明細のCSVを取り込み、未確認から確定する
- 仕訳を探して、理由つきで訂正・取消する
- 月の状況と帳票を見る。帳簿が壊れていないことを確かめて、手元に控える

作らないものは、銀行の自動連携、キーワードによる自動の仕訳、申告書とe-Taxです。理由は[設計](architecture.md)の「やらないと決めたこと」にあります。

## 構造: 画面は10、下書きと確定は別の場所

```
ホーム --次にやること--> 未確認 --Ctrl+Enter--> 仕訳帳
取引: 登録 / 未確認 / 取込 / 仕訳帳
帳票: 月次推移 / 損益計算書 / 貸借対照表 / 試算表 / 総勘定元帳 / 消費税
登録簿: 口座 / 勘定科目 / 取引先      設定: 事業者・締め・データ・見た目
```

未確認は自由に直せますが、確定した仕訳は、訂正と取消の手続きでしか変わりません。この違いが、画面全体の構造を決めます。確定の前の「確定する行」は、画面の中だけの印で、台帳には何も書きません。

## 骨格: 表1枚、フォーカスはキーボードで動かす

取引の登録は、1画面に入力欄と仕訳のプレビューを並べます。保存すると、種別・日付・口座を残して金額に戻ります。連続して入れるときに、手を止めないためです。

未確認の画面は表1枚で、行の中はTab、行の移動は矢印、Enterで確定する行に入れ、Ctrl/Cmd+Enterで確定します。一番こだわるのは、日本語入力の変換中のEnterです。変換を決めるEnterが、仕訳の確定や候補の選択として働いてはいけません。決めごとは[キー操作](spec/keyboard.md)に書きました。

## 表層: 数字は右寄せ、色だけに頼らない

金額は右寄せの等幅数字で、負の数には符号を付けます。藍を主の色にし、赤（朱）は訂正・取消・失敗のためにだけ使います。経費を赤くしないのは、普通の支出を警告に見せないためです。赤字は文字でも示します。

明暗はOSに従い、手動でも変えられます。フォントは端末標準の日本語書体で、外部から読み込みません。文字と背景は4.5:1以上、入力欄の枠は3:1以上を、色の定義から計算して確かめます。

## 通したことで変わった12の決定

1. [戦略] ホームは数字の一覧から始めず、「次にやること」（未確認の件数）を一番上に置く。
2. [戦略] デモを正式な機能にする。合成データを使い、一時フォルダだけに書く。
3. [要件] 保存前の仕訳のプレビューは、サーバーの計算で出す。画面の計算と保存の計算がずれる余地を消すため。
4. [要件] 事業の割合は、科目ごとに利用者が決めた既定値だけを使う。過去の入力から推測する案は、自動仕訳の特許の確認が済むまで入れない。
5. [要件] 振替は、科目ではなく「移動先の口座」を選ぶ形にする。
6. [構造] 取引先の名前を、台帳のハッシュの対象にする。そのため、`kamoku-ledger` に付随情報（`meta`）を足す。
7. [構造] 「確定する行」は画面だけの印にし、確定を明示の操作にする。取り消すための追記で、台帳を汚さずに済む。
8. [構造] ホームの数字は1回の通信にまとめる。小さな通信を重ねると、画面の描画が遅れる。
9. [構造] 免税事業者では、税区分の欄を既定で隠す。作者の設定が免税で、欄が多いと記帳が遅くなる。
10. [骨格] 科目の候補は、変換中の文字でも絞り、選ぶのは変換後のEnterだけにする。Safariの変換直後のEnterは、50ミリ秒の窓で無視する。
11. [骨格] 1文字のショートカットは、入力欄にいる間は働かせない。
12. [表層] 赤は訂正・取消・失敗に取っておき、赤字は文字でも示す。
