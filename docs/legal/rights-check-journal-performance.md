# 仕訳帳の高速化の作成記録

2026-10-15、Codexが既存のkamokuの仕様と実装から、台帳の派生索引、ページの
選択処理、回帰試験と合成データの測定プログラムを作成しました。他社サービスや
他の会計OSSのコード・画面・文面は参照していません。新しい依存はありません。

保存するイベントとハッシュ、会計・税のルールは変えません。測定には架空の
仕訳だけを使い、認証URL・Cookie・実データを公開しません。独立した参照計算と
読み取りレビューを行い、CIで保存層の回帰試験も確かめてからマージします。
従来の専門家確認などの残件は[既存の記録](rights-check.md)を引き継ぎます。
