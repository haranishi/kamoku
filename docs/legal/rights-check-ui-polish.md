# 権利の確認記録（画面の直し）: 新しい依存・素材・他社の表現は足していない

画面の直し（`ui/`、`e2e/`、`docs/screens.md` と画像）で、新しく足したものの権利と規約を確認した記録です（確認日は2026-10-15）。結論は3つです。依存・書体・画像・アイコンは、新しく足していません（選択欄の矢印とチェックの印は、自作の線画です）。他社の画面・文言・配色を写していません。互換を約束するように読めた設定の文は、事実に合わせて直しました。弁護士・弁理士・税理士の確認は受けていません。全体の方針は[ライセンス方針](license-policy.md)、公開前の確認は[権利と規約の確認記録](rights-check.md)にあります。

| 種類 | 内容 | 出どころ |

## 他社の画面・文言を写していないか

- 実装と評価の依頼書（`briefs/ui-fix-common.md`、`briefs/ui-experience.md`）に、他社の画面・文言・配色・アイコンを写さないことを書いた。使い慣れた型への近さを見る評価では、**実際の他社製品の画面を見ない・使わない・製品名を出力に書かない**と決めた。評価者には、「一般にこう置かれる型」のレベルの提案だけを求めた。
- `ui/`、`e2e/`、`docs/screens.md` に、他社の製品名は出ない（検索で確認）。READMEにある名前は、商標の注意書きと、互換や特許など事実の説明だけ。
- 読み取りレビュー（Codex）の2回目は、他社を写したと断定できる箇所は見つからないと答えた。ただし、他社の画面との見た目の比較は、権利の方針（見て似せない）のため、していない。近づけたのは、操作の流れと使い勝手だけ。

## 規約と、誤解を招く表現

- マネーフォワードの規約 第13条(14)（契約者による競合サービスの開発・改良の禁止）のため、マネーフォワードのサービスは、この作業のどの工程でも使っていない。マネーフォワード形式の書き出しも作っていない。
- 設定の書き出しの文が、「ほかのソフトで読める形」「ほかのソフト向けの全件」と、他社ソフトとの互換を約束するように読めた。実際は、このソフト独自の形式（`app: "kamoku"`）のJSONで、確定した記録と設定だけが入る。読み取りレビューの指摘で、内容を言う文に直した（「ほかのソフトで使うには、変換が必要です」と添えた）。
- 事業者名の補足が「帳票の見出しに出ます」と事実と違っていたので、「メニューの上に出ます」に直した。
- 消費税の言葉の説明は、サーバーの注意書きと、`kamoku-jp-tax` の表（国税庁の一次資料つき）と矛盾しないことを、読み取りレビューで確かめた。

## 個人情報・外部への送信・実データ

- 画面と文書の画像は、すべて `kamoku demo` の合成データ（架空の名前と数字）を撮ったもの。実在の帳簿・口座・人名は使っていない。
- 画面は、外へ通信しない（`ui/dev/check-policy.mjs` が、外のURL、`fetch` の置き場所、`innerHTML` などを見張る）。体験の評価では、評価者に、手元のサーバー（127.0.0.1）以外の外部サイトを開かないよう、依頼書で指示した（開いていないことの証拠は、取っていない）。
