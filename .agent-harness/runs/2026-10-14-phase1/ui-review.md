# 画面の直しの読み取りレビューと、対応

別の担当（Codex・読み取り専用）が、画面の変更を3回読みました（第1段・第2段・第3段は、どれも13件）。指摘のうち、コードで確かめて直すと決めたものは、実装担当（Opus・Codex）が直しました。設計担当が、試験を流し直して確かめています（2026-10-15）。コードや試験のコメントにある「第1段」「第2段」の番号は、この表の指摘の番号です。

## 第1段（担当2人の第1回の成果を取り込んだ直後）

| # | 問題 | 対応 | 守っている試験 |

## 第2段（担当2人の第2回の成果と、折り返し部品の統一を取り込んだ後）

| # | 問題 | 対応 |

| 4 | 事業者名の補足「帳票の見出しに出ます」が、事実と違う（メニューの上に出る） | 「メニューの上に出ます」に直した |

| 8 | 折り返し部品の塊が常に折り返し禁止で、文字の拡大で入れ物からはみ出す | 塊が枠より長いときだけ、中でも折れる形にした（`.nw`） |
| 9 | 月次推移の表の名前「グラフと同じ数字」が、今月より後の月を含むと成り立たない | 今月より後の月が表にあるときだけ、「今月より後の月は、表だけに出ます」にした |

| 13 | コンテナクエリ未対応の環境で、欄の並べ替えと見た目がずれる | 直さない。対応対象は、公開時点の最新版 |

## 第3段（担当4人の第3回の成果を取り込んだ後。最終）

別の担当（Codex・読み取り専用）が、第3回の差分（`ui/` 約83ファイル・約3,100行）を読み、13件を指摘した。コードで確かめて直したものは試験つき。「直さない」ものは `spec-issues.md` の12〜16に理由を書いた。

| # | 問題 | 対応 |
|---|---|---|
| 1 | 無視の送信中の行が、一覧の作り直しで確定する行にできる | 直さない（サーバーが先に届いた側で決め、後の側は断る。帳簿は壊れない） |
| 2 | 消費税の「仕入税額」の説明が、経過措置の仕入れで控除できる割合を掛けた額を足す事実と違う | 文を直した（売上税額と仕入税額を分け、経過措置を書いた）。試験の文も直した |
| 3 | 画面を離れた後に届く無視の応えが、新しい画面に反映されない | 直さない（サーバーには反映される。影響は、古い通知の「元に戻す」の見た目だけ） |
| 4 | 一覧から詳細Aを開いたあと、別の詳細Bへ移って閉じると、Aが開き直る | 1つ前の履歴が一覧のときだけ「戻る」を使う。通し試験を足し、直す前に赤になることを確認した |
| 5 | `back` が、訂正・詳細・初期設定や読めない符号も受ける | 戻り先にしてよい道だけに絞り、復号できない値は受けない。単体試験を足した |
| 6 | 通知の置き場所が、通知の高さを考えない | 直さない（実測していない。低い画面でまれ） |
| 7 | 画面の大きさを変えても、通知の置き場所を選び直さない | 大きさが変わったら選び直す |
| 8 | 開業日の説明が、帳票の数字がそろうと言い過ぎ | 「年の帳票の『期首』の列に、期首残高が入ります」と、コードの動きに合わせて言い直した |
| 9 | 売上も経費も差し引き0円の月を、記録なしと扱う | 直さない（金額は合う。サーバーが記録の有無を返せば正確になる） |
| 10 | 訂正を保存した通知の「仕訳を見る」が、戻り先を引き継がない | 保存の後の行き先と同じにした |
| 11 | `:has()` に対応しない環境で、消した誤りの印が残る | 直さない（画面は、ほかにも `:has()` を使っている。対応は公開時点の最新版） |
| 12 | ホームの「年の利益の期間」の試験が、期間と累計の食い違いを通す | 累計も外す形に直し、差し引き0円の月の場合を足した |
| 13 | 無視の連打の試験が、前の応えを待って次を送る（直列）ことを確かめていない | 応えを保留して確かめる形に強めた。直列化を壊すと赤になることを確認した |

見たが問題なしとされたもの（第3段）: 締めた日を含む境界と訂正元の日付の判定、今月の前月実額と開業月の「1か月分」、税区分の仮の値と確定の一致、子の口座へのリンクの期間、1文字キーを切る処理が止めてはいけないキーを止めていないこと、IME の判定、通知の見張りの後始末、`--bar-bottom` と固定バー、既存の試験を弱めた変更がないこと、新しい日本語に他社固有の文言や互換の約束がないこと。確かめていない: 読み上げの重複、通知の性能。

## 見たが問題なしとされたもの

月次の列と年間合計、振替だけの月、子が1つの親を畳んでも合計が変わらないこと、仕訳帳の「合計」の文とサーバーの意味（取消済みを含み、訂正は最新の版を1回だけ数える）の一致、消費税の短い説明（数字を書いていない。サーバーの注意書きと矛盾しない）、キー処理の `shouldIgnoreKey`、設定の目次の `aria-current`、画面の生成と色の規則。他社を写したと言える箇所は見つかりませんでした。他社の画面との比較は、権利の方針のため、していません。

## 確かめていないこと

Safari・Firefox・iPhone の実機・日本語入力の実機での操作、読み上げ、文字を200%に拡大したときの実描画。
