# 画面の仕様（1）日々の記帳

画面は、ブラウザで開く1つのページの中で、アドレスの `#/` 以降を切り替えて表示します。ほかの画面は[画面の仕様（2）](screens-other.md)、キー操作は[キー操作](keyboard.md)にあります。

共通の枠は、左のサイドバー（幅1024px以上）と、画面下の5項目のバー（幅768px未満。ホーム・登録・未確認・仕訳帳・メニュー。メニューは全項目を引き出しで出す）です。768〜1023pxは、閉じられるサイドバーにします。サイドバーは「ホーム」「取引（登録・未確認・取込・仕訳帳）」「帳票」「登録簿（口座・勘定科目・取引先）」「設定」の順です。

## SC-01 ホーム `#/`

```
+--------+-------------------------------------------------+
| kamoku | 2026年10月 v                       [取引を登録]  |
|        +-------------------------------------------------+
| ホーム | 次にやること                                    |
| 取引   |   未確認の取引が 12件あります（出金 45,600円）   |
|  ...   |   [未確認を開く  g i]                           |
| 帳票   | [今月の売上][今月の経費][今月の利益][今年の利益] |
| 登録簿 | 12か月の推移（棒: 売上と経費、線: 利益）         |
| 設定   | [口座の残高] [経費の上位5科目] [台帳の状態]      |
+--------+-------------------------------------------------+
```

- 一番上は「次にやること」。未確認が0件なら「未確認はありません」と、次の候補（月末なら帳票の確認）を出す。
- 数字には、前の月との差を添える。利益が負なら「赤字」と書く。
- 台帳の状態には、整合性（OK/要確認）、末尾のハッシュの先頭8桁、写し取るボタンを置く。
- グラフは、今月より後の月を描かない（0へ落ちたように見えるため）。過去の年は12か月すべて描く。
- 状態: 読込中は骨組み表示、データなしは「最初の取引を登録しましょう」。

## SC-02 取引を登録 `#/entry`、訂正 `#/entry/<id>`

```
 取引を登録
 (支出) (収入) (振替)          <- 1 2 3 で切り替え
 日付 [2026-10-05 (月)]   金額 [        11,000] 円
 科目 [通信費        v]   口座 [エポスカード  v]
 税区分 [課税仕入10% v]   取引先 [              ]
 摘要 [                                        ]
 事業の割合 [ 70 ] %      -> 事業主貸 3,300円
 仕訳のプレビュー
   借方 通信費 7,700（税700） | 貸方 エポスカード 11,000
   借方 事業主貸 3,300        |
 [保存して続ける  Ctrl+Enter]  [保存]  [やめる  Esc]
```

- 振替は、科目の代わりに「移動先の口座」を選ぶ。税区分と割合は出さない。
- 免税事業者のときは、税区分の欄を隠す。隠れている間は、科目の既定の税区分を入れず、空（対象外）で送る。「詳細」で欄を出したときだけ、科目の既定値が入る。
- 「仕訳で入力」に切り替えると、行を足せる表（借貸・科目・金額・税区分・メモ）になる。貸借の差を常に表示し、0のときだけ保存できる。
- 訂正のときは、理由の欄が出る（必須）。元の値との差分を、保存前に見せる。
- テンプレート（よく使う取引）から入力を呼び出せる。保存時に「テンプレートに登録」を選べる。
- 「保存して続ける」は金額に戻る。「保存」は、保存した仕訳の詳細（`#/journal/<id>`）を開く。

## SC-03 未確認 `#/inbox`

```
 未確認 12件  [口座 v] [検索 /]        確定候補 3件
 候補 日付       摘要            金額    科目    税  取引先  割合
 [x]  10/01     ○○ストア      -1,650  [消耗品費] ..  ......  100
 [ ]  10/02     ○○鉄道          -420  [        ] ..
 ...
 --------------------------------------------------------------
 確定候補 3件  入金 0円  出金 8,200円      [確定する  Ctrl+Enter]
```

- 表は日付の昇順。1ページ200行まで。金額の列は、入金を正、出金を負で右寄せにし、色だけに頼らず符号も付ける。
- 「確定候補」は画面の中だけの印で、台帳には何も書かない。確定するまでは、やり直しも取消も要らない。
- 科目が空の行は、確定候補にできない（行に理由を出す）。
- 行の操作: 取り込まない（`x`）、無視した行の表示、元に戻す。
- 空の状態: 「未確認はありません。明細を取り込むか、取引を登録してください」と、2つの入口を出す。

## SC-04 取込 `#/import`

3段階です。(1) 口座を選び、CSVを置く（ドラッグまたは選択）。(2) 列の対応を確かめる。(3) 結果を見て取り込む。

- (2)は、先頭20行のプレビューと、日付・摘要・金額の対応を選ぶ欄を並べる。文字コードの判定結果と、符号の向きを直せる。
- 各行に「新規」「重複」「読めない」を付け、件数を上に出す。読めない行は理由を出す。
- 取り込み後は「未確認を開く」と「別のファイルを取り込む」を出す。

## SC-05 仕訳帳 `#/journal`、詳細 `#/journal/<id>`

- 絞り込み: 期間・科目・口座・金額の範囲・文字列・状態（有効/取消済み）・種別。条件はアドレスに入れ、戻る操作で復元できる。
- 一覧の列: No、日付、摘要、借方の科目、貸方の科目、金額、状態。複合仕訳は「ほか2行」と出す。
- 詳細（右からの引き出し）: 明細の表、取引先、メモ、履歴（登録・訂正・取消を時系列に。理由つき）、訂正と取消のボタン。取消は、理由の入力と、赤系の確認ボタンを要する。
