# 設計書の読み取りレビューと、その対応（2026-10-14）

別のモデル（Codex。読み取り専用）に、実装の前に `docs/spec/` と関連文書を点検してもらいました。指摘は30件（🔴17、🟡13）でした。以下は、1件ずつの判断です。「直した」は設計書を直したこと、「見送り」は理由つきで直さなかったことです。

| # | 指摘の要点 | 判断 |
|---|---|---|
| 1 | `Entry::meta` が既存コードに無い | 直さない。依頼R1のT1で足す仕事で、符号化の互換（付随情報が無いイベントのハッシュは変わらない）も依頼書に定義済み |
| 2 | 経過措置の控除額が国税分だけで、国税と地方税の合計の税額に足すと単位が混ざる | 直した。仕入税額は「含まれる税額（合計）× 割合」を明細ごとに切捨て。`transitional_credit` は使わない（`api-reports.md`） |
| 3 | 経過措置の判定日が、明細の支払日になりうる | 直した。日付は課税仕入れの日にする案内、下書きの日付の編集、警告。課税仕入れ日を別に持つ案は範囲が広がるので見送り |
| 4 | 指紋と出現番号では、部分的に重なるファイルで本物の取引を落とす | 一部を直した。取引番号の列、重複の行を理由つきで見せて選べる取り込み。完全な保証はできないと明記した |
| 5 | 試算表が期間内の動きか累計か不明 | 直した。期首・動き・期末の4列。元帳と同じ基準 |
| 6 | 当期利益の位置と、年またぎの繰越の規則が帳票ごとに不明 | 直した。仮想の繰越を全帳票で共通にし、当期純利益を資本の行に入れ、数字の例を置いた |
| 7 | 期首残高が全部0のとき仕訳を作れない | 直した。0円の行は入れず、残らなければ仕訳なし。債務超過は元入金が借方 |
| 8 | カード購入と引き落としの二重計上 | 一部を直した。相手科目が口座なら税区分と割合を断り、2回に分ける手順を例示。機械的に二重を見つける仕組みは作らない（運用の問題として文書に書く） |
| 9 | 割合0や端数で0円の明細ができる | 直した。0円の明細は作らない |
| 10 | 確定時の下書き・取引先・変更履歴が同じトランザクションか不明 | 直した（`data-model.md` 決まり3） |
| 11 | 二重起動でメモリ台帳が古くなる | 書き込み前の末尾照合と `stale` で守る。決まり13に明記 |
| 12 | 再送で二重登録、古い版の訂正の競合 | 直した。`client_id` と `expected_revision`。プレビューの照合値は見送り（同じ入力・同じ設定なら決定的で、変わるのは別タブで設定を変えたときだけ） |
| 13 | 壊れた台帳の読み込み手順が無い | 直した。壊れた連番の手前までで作る（決まり14） |
| 14 | Cookieの値を照合する規定が無い | 直した |
| 15 | `Origin` が無い変更要求を通してしまう | 直した。必須にし、`Sec-Fetch-Site` も見る。`/?t=` の応答も `no-store` |
| 16 | CSVの式の実行防止が不足 | 直した。タブとCRも対象。全角の `＝` などは式として実行されないはずだが、実機での確認は試験に残る |
| 17 | IMEの50msに保証が無く、暗黙のフォーム送信を防げない | 直した。判定の順序、Safariの後追いの `keydown` の `preventDefault`、`repeat`、暗黙送信に頼らない。50msは経験値と明記し、Safari・Firefoxは人の確認 |
| 18 | `restore` の状態遷移が曖昧 | 直した（状態の表） |
| 19 | 科目の既定割合が「空なら」では効かない | 直した。「変える前の科目の既定値と同じなら更新」の規則 |
| 20 | 仕訳の形の税区分と税額の検査が薄い | 一部を直した（`NT` は0）。区分と借貸の細かい検査は、返品や値引きを許すため見送り |
| 21 | 税額の計算単位が、関数の注意書きと食い違う | 注記した（記帳上の目安。請求書の税額とは別） |
| 22 | 課税区分が現在の1値だけ | 未対応と明記し、画面の文面を弱めた |
| 23 | WAL・SHM・バックアップの権限、Windows、デモの保存先 | 直した（決まり15）。Windowsは既定の保存先に任せる |
| 24 | 親の科目の扱いと二重計上 | 直した。試算表は平ら、貸借対照表は自分の分と子の合計 |
| 25 | 摘要の正規化、複数列、不正バイト、0円行 | 直した |
| 26 | 月次のCSV、消費税のCSV、貸借対照表の期間、12個固定の月 | 直した。期間は同じ暦年の中だけ |
| 27 | Enterの優先順位、確定候補の保持、入出金の合計 | 直した |
| 28 | 集計値がJavaScriptの安全な整数を超える | 直した（決まり16） |
| 29 | 50ms と 100ms、5分の範囲、完了条件 | 直した。サーバーは50ms、画面は100ms。完了条件に `manual` を加えた |
| 30 | 規約と適合の言い方が強い | 直した。第13条(14)の言い方、適合は機能と運用の両方で未評価 |

レビューが確認できなかったこと: ブラウザの実機、性能、税理士の確認、特許の請求項。これらは別の工程で扱います。
