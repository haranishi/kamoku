# 利用者の物語と受け入れ条件（ブラウザのお試し版）

インストールせず、静的ファイルを開くだけで kamoku を試すときの条件です。番号は試験の名前かコメントに書きます。`tools/check-spec-trace.py` が見ます。

## US-14 ブラウザで試す（インストールなし）

参加者は、ビルドもインストールもせずに、架空の帳簿が入った kamoku をブラウザだけで触りたい。入力は端末の中だけで、閉じるか再読み込みで消えてほしい。

- AC-14.1 [e2e] 静的ファイルの置き場（サブパス）を開くと、架空の帳簿（サーバー版のデモと同じ内容）の画面が出る。追加の操作は要らない。
- AC-14.2 [e2e] 取引を登録すると仕訳帳と帳票に反映される。再読み込みすると最初の帳簿に戻る。
- AC-14.3 [e2e] 開いてから操作するまで、配信元以外への通信が0件。`/api/` への要求はネットワークに出ない。
- AC-14.4 [e2e] 仕訳帳のCSV、帳票のCSV、全件のJSONをダウンロードできる。
- AC-14.5 [e2e] 帳簿の控え（バックアップ）は作れないことを、日本語で理由と代わりの方法（ソースから動かす）を添えて示す。
- AC-14.6 [e2e] 画面の案内の帯が、お試し版の内容（架空の帳簿・このブラウザの中だけで動き、閉じるか再読み込みで元に戻る・税の計算は参考値・「今日」は帳簿に合わせた2026年9月30日）になり、ソース（GitHub）へのリンクと「最初の帳簿に戻す」がある。幅390・768・1440で横スクロールが出ず、本体の操作を隠さない。
- AC-14.7 [rust] ブラウザ版の入口は、サーバー版と同じ経路表・本文の上限・Content-Type の検査を使い、同じ要求に同じ内容を返す。デモの台帳の末尾ハッシュは、サーバー版のデモと同じ。
- AC-14.8 [e2e] 起動に失敗したとき（WASMを読み込めないなど）は、日本語の案内が出る。
