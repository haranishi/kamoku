# 標準の勘定科目

kamokuが最初に用意する勘定科目の一覧です。名前は、国税庁の青色申告決算書（一般用）の項目名に合わせました。決算書の行名と違う科目（外注費など）は、「決算書の行」の欄に行名を書いています。突き合わせの記録は[権利の確認記録（Phase 1）](legal/rights-check-phase1.md)にあります。

このファイルは手で直しません。`crates/kamoku-books/src/standard.rs` を直してから、`cargo run -p kamoku-books --example accounts_doc > docs/accounts.md` で作り直します。中身とコードがずれると、`kamoku-books` の試験が落ちます。

「既定の税区分」と「既定の割合」は、科目を選んだときに入る初期値です。勘定科目の画面で変えられます。状態が「無効」の科目は、使うときに有効にします。

「（空欄）」は、決算書に決まった行が無い経費です。決算書では、空いている行に科目名を書いて使います。
