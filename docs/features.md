# 機能の一覧: できること、まだのこと、作らないこと

クラウド会計を使ったことのある人が、「あの機能はあるか」を探せるように、機能ごとの状態をまとめました。特定の製品との比較ではありません。画面の見た目や文言も、どの製品にも似せていません。

- ✅ 動く。試験を通している（実際の帳簿で長く使った記録は、まだありません）
- 🚧 一部だけ動く。限りを書いている
- 📋 作る予定。順序は[ロードマップ](roadmap.md)
- 🚫 作らない。理由と、見直す条件を書いている

## 日々の記帳

| 機能 | 状態 | 備考 |
|---|---|---|
| 開いてすぐ、次にやることが分かるホーム | ✅ | 未確認の件数から、確定の画面へ入れる |
| 取引の登録（収入・支出・振替） | ✅ | 日付・金額・科目・口座だけで登録できる |
| 保存前の仕訳のプレビュー | ✅ | 借方・貸方・税額を、保存の前に見られる |
| 家事按分 | ✅ | 事業の割合を指定。残りは事業主貸に入る。科目ごとの既定の割合も持てる |
| 仕訳の直接入力（複合仕訳） | ✅ | 貸借が合うときだけ保存できる |
| 仕訳帳の検索・絞り込み | ✅ | 期間、科目、口座、金額、文字列 |
| 理由つきの訂正と取消、履歴 | ✅ | 元の記録は残る。過去の記録は書き換えない |
| よく使う取引のテンプレート | ✅ | |
| 定期的な取引の下書き | 📋 | Phase 2。利用者が決めた日付と内容だけで作る |
| 取引先（登録番号の形式の検査つき） | ✅ | 実在の確認はしない |

## 明細の取込

| 機能 | 状態 | 備考 |
|---|---|---|
| 銀行・カードの明細CSVの取込 | ✅ | UTF-8とShift_JIS。列の対応は画面で確かめて、口座ごとに覚える |
| 二重に取り込まない | ✅ | 同じファイルの再取込、期間の重なりを見分ける。限りは[データの形](spec/data-model.md)の決まり4 |
| 未確認の一覧をキーボードで確定 | ✅ | 日本語入力の変換中のEnterでは確定しない |
| 銀行・カードの自動取得 | 🚫 | 電子決済等代行業に当たりうる。弁護士か金融庁の見解が得られたら見直す |
| キーワードによる科目の自動提案 | 🚫 | 他社の特許がある。弁理士の確認が済んだら見直す |

## 帳票と税

| 機能 | 状態 | 備考 |
|---|---|---|
| 月次推移、損益計算書、貸借対照表、試算表、総勘定元帳 | ✅ | 年またぎは帳票の上で繰り越す |
| 消費税の集計（参考値） | 🚧 | 本則課税の見込みだけ。簡易課税・特例は計算しない。税理士の確認前 |
| インボイスの経過措置（免税事業者等からの仕入れ） | 🚧 | 割合は日付の表で持つ。適用条件と仕入先ごとの上限は見ない |
| 年次の締めの仕訳 | 🚧 | 帳票の上の繰越だけ。台帳への締めの仕訳は未対応 |
| 青色申告決算書の項目への集計 | 📋 | Phase 3。科目には、決算書の行名を持たせてある |
| 固定資産と減価償却 | 📋 | Phase 3 |
| 申告書の作成、e-Taxの送信 | 🚫 | v1の範囲外。税理士の協力者が現れたら見直す |
| 請求書・見積書の作成 | 📋 | 候補。v1の範囲外 |

## データ・安全・共有

| 機能 | 状態 | 備考 |
|---|---|---|
| データは自分のパソコンのSQLite1つ | ✅ | 普通の表なので、ほかの道具でも読める |
| 追記だけの台帳と、整合性の検査 | ✅ | 改ざんを検知する（防止はしない） |
| 末尾のハッシュの控えと照合 | ✅ | 末尾の削除を見つけるには、控えを台帳の外に残す |
| バックアップ、JSON・CSVの書き出し | ✅ | CSVは税理士さんがExcelで開ける形（BOMつきUTF-8） |
| 弥生形式のCSV | 📋 | Phase 3。公式の仕様を確かめてから |
| マネーフォワード形式の書き出し | 🚫 | 同社の規約が競合・類似サービスの開発を禁じているため |
| 領収書・証憑の保管と検索 | 📋 | Phase 2 |
| 電子帳簿保存法への「対応済み」 | 🚫 | 認証を取っておらず、言えない。履歴を残す機能までは用意する |
| 複数人での利用、権限の管理 | 🚫 | 1人が自分のパソコンで使う前提 |
| クラウドへの同期 | 🚫 | 外へ通信しない |
