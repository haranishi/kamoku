# 画面の仕様（2）帳票・登録簿・設定

日々の記帳の画面は[画面の仕様（1）](screens-main.md)にあります。

## SC-06 帳票 `#/reports/<name>`

上にタブを並べます。「月次推移」「損益計算書」「貸借対照表」「試算表」「総勘定元帳」「消費税」の6つです。

- 期間の選び方は共通で、「年」「月」「自由な期間」。自由な期間は、同じ暦年の中だけ（またぐと理由を出す）。貸借対照表は日付を1つ選ぶ。選んだ期間はアドレスに入れる。
- 各画面の右上に「CSVで書き出す」を置く。文字コードを選べる（既定はBOMつきUTF-8）。
- 表は、親の科目の下に子の科目をインデントして並べ、親の行に合計を出す。負の数は「-1,200」と符号で示す。
- 自由な期間で始めが終わりより後なら、誤りを始めの欄に結び付けてフォーカスを移し、打ち直したら消す。誤りのあいだは、見出しの横に「前の期間（2026-04-01 〜 2026-06-30）を表示中です。」と出し、表は前の期間のまま残す（AC-08.7）。
- 月次推移は、棒グラフ（売上と経費）と線（利益）に、同じ数字の表を並べる。グラフには、読み上げ用の要約文を付ける。表の直前に「表は今月までです。11月と12月は、その月になるか、記録ができたら出ます。」と書く。
- 総勘定元帳は、科目を選ぶと、日付順の行と残高の推移を出す。行（`data-entry-id` を持つ）から仕訳の詳細に飛べ、`j` `k` で行を動かせる。選んだ科目が子の口座を持つとき（「普通預金・その他の預金」など）は、表の上に「この科目の動きは、口座「…」の側にあります。」と、同じ期間の口座ごとの元帳へのリンクを出す（親に直接の記帳があるときは、その旨に文を変える）。科目の候補は、口座の種類の言葉（よきん・ふつう・くれじっと など）でも探せる。口座を先に並べる（同じ名前の親の科目は直接の記帳しか出ず、先頭で選ばれると0行になるため）。合うものが無いときは探し方の一言を出す。
- 消費税は、税区分ごとの課税標準と税額、経過措置の内訳、納付額の見込み（参考）を出す。画面の上に「参考値。簡易課税・特例は反映していません」と常に出す。注意は、どの幅でも1行の要点と「くわしく」に畳み、納付額の見込みと表を先に出す。税額の説明を一言添える: 売上税額は明細ごとの税額（登録時に端数を処理した額）の合計。仕入税額は、通常の仕入れは明細ごとの税額の合計、経過措置の仕入れは控除できる割合を掛けた額の合計。どちらも税込の合計から出した額と数円ちがうことがある。免税事業者の設定のときは、冒頭に「設定上は免税事業者として表示しています。申告の要否は、国税庁の案内か税理士に確かめてください」と出す。

## SC-07 口座 `#/wallets`

口座ごとに、名前・型・残高を出す。新しい口座は「現金」「預金」「クレジットカード」「電子マネー」から作る。残高は、カードなら「未払い額」と書く。口座をたどると、その口座の総勘定元帳と、未確認の件数に飛べる。

## SC-08 勘定科目 `#/accounts`

分類（資産・負債・資本・収益・費用）で並べ、名前と読みで検索できる。標準の科目は名前を変えられるが、分類は変えられない。使わない科目は無効にできる（過去の仕訳は変わらない）。科目ごとに、既定の税区分と既定の事業割合を決められる。

## SC-09 取引先 `#/partners`

名前、読み、登録番号（T+13桁。形式だけを検査）、メモ。仕訳の入力で新しい名前を打つと、その場で追加できる。

## SC-10 設定 `#/settings`

- 事業者: 事業者名（必須。空のまま保存すると、欄の下に誤りを出して欄へ移る）、開業日、課税の区分（免税/課税）、登録番号、消費税の端数処理（切捨て/四捨五入/切上げ）。開業日の説明は、初期設定と同じ文にする（下）。幅1280px以上は、節の中を左右2列に並べる。
- 締め: 「この日以前は変更しない」日付。
- 期首残高: 初期設定と同じ入力で見直せる（仕訳帳からは訂正できない）。
- データ: 整合性の検査、末尾のハッシュの写し取りと照合、バックアップ、JSONとCSVの書き出し。
- 見た目: ライト/ダーク/OS、行の密度（標準/狭い）。この項目は、ブラウザの中にだけ保存する。

## SC-00 初期設定 `#/setup`

初回だけ出る、4段階の画面です。(1)事業者名と課税の区分。(2)口座を追加（現金は最初から1つ用意）。(3)期首残高（開業日の残高。分からなければ0で進める）。(4)確認して始める。各段階で保存し、戻れる。

- 閉じて開き直すと、最後に保存した段階の次から始め、済んだ段階には印を残す。保存したかどうかは、サーバーに保存された事業者名と開業日、期首残高の仕訳の有無で決める（期首残高をすべて0円で保存すると仕訳ができず、(3)は済みと読めない）。
- 文字の欄のEnterは次の欄へ進み、最後の欄のEnterは「保存して次へ」と同じ。変換中のEnterとボタンの上のEnterは、今までどおり。
- 開業日の欄の説明は、設定と同じ2行にする: 「この日より前の日付で取引を登録するときは、確認が出ます。期首残高の日付の初期値にもなります。」「年の途中から記帳を始めるときは、その年の1月1日にすると、年の帳票の「期首」の列に、期首残高が入ります。」
- (4)の確認画面に、科目ごとの期首残高と元入金を並べる。完了の通知は8秒出す。

## 共通の部品

- 通知（トースト）: 3〜5秒で消える。読み上げに対応し、フォーカスを奪わない。エラーは自動で消さない。
- 通知の置き場所は、フォーカスのある欄・表の行・小窓の見出し（閉じる）と下のボタンの並び（保存・確定）に重ねない。小窓が無いとき、幅767px以下は上の帯のすぐ下、広い幅は本文の上の真ん中（そこに押せる物があれば右下）。小窓が開いているときは、外に余白があれば外（1440pxの仕訳の詳細なら板の左）、無ければ見出しの下、次に下のボタンの並びの上。フォーカスが通知の下の欄へ移ったら、通知のほうがどく。通知の中のボタンにフォーカスがある間は動かさない。続けて無視したときの「元に戻す」の通知は、新しいものが前のを置き換えて1つだけ出す（積み重なると表の操作を覆うため。前の行は ⌘Z か「無視した行」から戻せる）。
- 確認の画面: 取り消せないこと（取消・確定）の前に出す。取消は理由、確定は件数と合計。
- 空の状態: 何も無い理由と、次の一手を1つ出す。
- 読込中: 300ms以上かかるときだけ、骨組みを出す。
- 失敗: 原因と直し方を日本語で、入力欄のすぐ下に出す。
