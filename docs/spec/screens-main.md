# 画面の仕様（1）日々の記帳

画面は、ブラウザで開く1つのページの中で、アドレスの `#/` 以降を切り替えて表示します。ほかの画面は[画面の仕様（2）](screens-other.md)、キー操作は[キー操作](keyboard.md)にあります。

共通の枠は、左のサイドバー（幅1024px以上）と、画面下の5項目のバー（幅768px未満。ホーム・登録・未確認・仕訳帳・メニュー。メニューは全項目を引き出しで出す）です。768〜1023pxは、閉じられるサイドバーにします。サイドバーは「ホーム」「取引（登録・未確認・取込・仕訳帳）」「帳票」「登録簿（口座・勘定科目・取引先）」「設定」の順です。

高さが520px以下の画面（文字を200%に拡大した画面など。幅767px以下）では、下のバーを隠し、上の帯の「メニュー」から全項目を開きます。下に固定した帯（確定の帯など）は画面の下の端に付けます。

## SC-01 ホーム `#/`

```
+--------+-------------------------------------------------+
| kamoku | 2026年10月 v                       [取引を登録]  |
|        +-------------------------------------------------+
| ホーム | 次にやること                                    |
| 取引   |   未確認の取引が 12件あります（出金 45,600円）   |
|  ...   |   [未確認を開く  g i]                           |
| 帳票   | [今月の売上][今月の経費][今月の利益][今年の利益] |
| 登録簿 | 12か月の推移（棒: 売上と経費、線: 利益）         |
| 設定   | [口座の残高] [経費の上位5科目] [台帳の状態]      |
+--------+-------------------------------------------------+
```

- 一番上は「次にやること」。未確認が0件なら「未確認はありません」と、次の候補（月末なら帳票の確認）を出す。
- 数字には、前の月との差を添える。利益が負なら「赤字」と書く。今月（と、記録のある先の月）はまだ途中なので、差と矢印の代わりに前の月の実額を「9月は 500,500円（1か月分）」と添える（丸1か月と比べると大きなマイナスに見えるため）。前の月が開業前なら何も出さず、開業した月で開業日が1日でなければ「1か月分」とは書かない。
- 年の利益の期間は、開業日がその年の途中で、開業の月より前に記録が無いときだけ「4月〜10月」と書く。記録があれば、サーバーの集計どおり「1月〜」のまま。
- 台帳の状態には、整合性（OK/要確認）、末尾のハッシュの先頭8桁、写し取るボタンを置く。
- グラフは、今月より後の月を描かない（0へ落ちたように見えるため）。過去の年は12か月すべて描く。凡例は名前だけ（売上・経費・利益）にし、棒・線・点の見分け方は凡例の下の1行にまとめる。赤字の月には、その月の列の真下（枠の下の帯）に額（例「-2.5万」）を添える。棒や点の上には載せない。隣り合う月で重なるときは次の段へずらし（段は2つまで）、それでも置けない月だけ省く。
- 状態: 読込中は骨組み表示、データなしは「最初の取引を登録しましょう」。

## SC-02 取引を登録 `#/entry`、訂正 `#/entry/<id>`

```
 取引を登録
 (支出) (収入) (振替)          <- 1 2 3 で切り替え
 日付 [2026-10-05 (月)]   金額 [        11,000] 円
 科目 [通信費        v]   口座 [エポスカード  v]
 税区分 [課税仕入10% v]   取引先 [              ]
 摘要 [                                        ]
 事業の割合 [ 70 ] %      -> 事業主貸 3,300円
 仕訳のプレビュー
   借方 通信費 7,700（税700） | 貸方 エポスカード 11,000
   借方 事業主貸 3,300        |
 [保存して続ける  Ctrl+Enter]  [保存]  [やめる  Esc]
```

- 振替は、科目の代わりに「移動先の口座」を選ぶ。税区分と割合は出さない。
- 免税事業者のときは、税区分の欄を隠す。隠れている間は、科目の既定の税区分を入れず、空（対象外）で送る。「詳細」で欄を出したときだけ、科目の既定値が入る。
- 「仕訳で入力」に切り替えると、行を足せる表（借貸・科目・金額・税区分・メモ）になる。貸借の差を常に表示し、0のときだけ保存できる。表のすぐ上に、借方と貸方の1行の説明（借方の合計と貸方の合計を同じにする）を置く。幅640px以上は1つの明細を2段にする（1段目: 借方か貸方・科目・金額。2段目: 税区分・メモ・行を消す）。幅390では、長い税区分を選んだときだけ、欄の下に名前を全部出す。
- 訂正のときは、理由の欄が出る（必須）。元の値との差分を、保存前に見せる。
- テンプレート（よく使う取引）から入力を呼び出せる。保存時に「テンプレートに登録」を選べる。
- 「保存して続ける」は金額に戻る。「保存」は、保存した仕訳の詳細（`#/journal/<id>`）を開く。

## SC-03 未確認 `#/inbox`

```
 未確認 12件  [口座 v] [検索 /]        確定する行 3件
 候補 日付       摘要            金額    科目    税  取引先  割合
 [x]  10/01     ○○ストア      -1,650  [消耗品費] ..  ......  100
 [ ]  10/02     ○○鉄道          -420  [        ] ..
 ...
 --------------------------------------------------------------
 確定する行 3件  入金 0円  出金 8,200円      [確定する  Ctrl+Enter]
```

- 表は日付の昇順。1ページ200行まで。金額の列は、入金を正、出金を負で右寄せにし、色だけに頼らず符号も付ける。
- 「確定する行」は画面の中だけの印で、台帳には何も書かない。確定するまでは、やり直しも取消も要らない。
- 科目が空の行は、確定する行にできない（行に理由を出す）。
- 行の操作: 無視（`x`）、無視した行の表示、元に戻す（Ctrl/Cmd+Z）。無視は、押した順に1件ずつ送る。押したらすぐ次の行へフォーカスを移し、送っている行は薄く出す。送れなかった行は一覧に戻し、行の下に理由を出す。
- 科目の欄の仮の文字は「科目（必須）」。税区分の選択肢の名前は、取引を登録する画面と同じ（経過措置の2つだけ、末尾の「（免税事業者等から）」を省き、欄の title に正式な名前を出す）。手で選んでいない空の税区分は、確定したときの扱いを仮の値で見せる: 科目の既定が対象外なら「対象外（既定）」、既定が行の向きで使えない科目は「対象外」、科目が無い行は「科目で決まる」。
- 列の見出しは「事業の割合」（説明: 仕事に使った分の割合。残りは事業主貸に入る）と「金額（円）」。「くわしく」は、開くと「閉じる」に変わり、名前に行の日付・摘要・金額が入る。確定の通知は、1件なら「No.212」だけにする。
- 幅600px未満はカードにし、1段目に摘要と、右へ金額と「無視」、2段目に科目と「くわしく」を置く（Tabの順も見た目の順）。印を付けた行には「確定する」の札を出す。高さ520px以下では、確定の帯を1行にする。
- 空の状態: 「未確認はありません。明細を取り込むか、取引を登録してください」と、2つの入口を出す。

## SC-04 取込 `#/import`

3段階です。(1) 口座を選び、CSVを置く（ドラッグまたは選択）。(2) 列の対応を確かめる。(3) 結果を見て取り込む。

- (2)は、先頭20行のプレビューと、日付・摘要・金額の対応を選ぶ欄を並べる。文字コードの判定結果と、符号の向きを直せる。
- 各行に「新規」「重複」「読めない」を付け、件数を上に出す。読めない行は理由を出す。
- 取り込み後は「未確認を開く」と「別のファイルを取り込む」を出す。(3)で新規が0件なら、要約のすぐ下に「未確認を開く」（その口座で絞った未確認）を出す。
- 口座は、前に取り込めた口座を初期値にする（ブラウザに覚える。無効にした口座は使わない）。(2)と(3)の「戻る」「確かめる」「N件を取り込む」は、画面の下に付く帯に置く。(3)から「戻る」と、直前に選んだ列の対応が(2)に残る（ファイルを選び直したときと、文字コードを選び直したときだけ、推測に戻る）。
- 文字コードは選択欄1つにまとめる（「自動で判定（Shift_JIS）」）。日付の列に日付として読めない行が半分を超える列を選んだら、「確かめる」の前に、欄の下で選び直しを促す。

## SC-05 仕訳帳 `#/journal`、詳細 `#/journal/<id>`

- 絞り込み: 期間・科目・口座・金額の範囲・文字列・状態（有効/取消済み）・種別。条件はアドレスに入れ、戻る操作で復元できる。
- 一覧の列: No、日付、摘要（取引先は摘要の下の行に、本文の色で）、借方の科目、貸方の科目、金額（円）、詳細。複合仕訳は「ほか2行」と出す。「詳細」の列に出す札は、訂正と取消の行だけ。入れ物が900px未満のときはカードにし、借方と貸方を別の行に出す（金額に「円」を添える）。ページ送りは、一覧の上と下に置く。
- 詳細（右からの引き出し）: 明細の表、取引先、メモ、履歴（登録・訂正・取消を時系列に。理由つき。見出しの下に「記録のハッシュ」が何かを1行で書く）、訂正と取消のボタン。取消は、理由の入力と、赤系の確認ボタンを要する。
- 締めた日以前の仕訳は、詳細を開いた時点で「…まで締めてあるため、この仕訳は訂正も取消もできません。」と出し、訂正と取消のボタンを止める（理由を書いて確定してから断られないように）。
- 詳細の板を閉じると、開く前の画面へ戻る。元帳やホームから開いたなら、その画面の、開いた行へ。訂正を挟んでも、検索の条件のままの一覧へ戻る。
