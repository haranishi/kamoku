# 非機能の要件: 安全・速さ・見やすさ

数字と、WCAG 2.1 AAへの準拠は**目標**です。測って、確かめて公開するまでは、READMEで「達成した」と書きません。

## 安全

- 待ち受けは `127.0.0.1` だけ。外のネットワークからは届かない。
- 起動ごとに変わる合言葉（128ビット）、Cookie（HttpOnly・SameSite=Strict）、`Host` と `Origin` の検査で、同じパソコンのほかのページからの操作と、DNSの付け替えを防ぐ（[通信の共通のきまり](api-common.md)）。
- 外へ通信しない。サーバーはHTTPクライアントを持たない。画面は、外部のスクリプト・フォント・画像・計測を読み込まない。CSPで `default-src 'self'` にして、これを強制する。
- 画面の文字は、`textContent` と属性の設定だけで作る。`innerHTML` は使わない（試験で、ソースの検索により確かめる）。
- 入力はサーバーで必ず検査する。画面の検査は、使いやすさのためだけにある。
- JSONの本文は1MB、CSVは10MBまで。CSVは行数20万、1行の列数1,000、全体のセル200万、1つの欄は64KBまで。
- DBは0600、新しく作るフォルダは0700（Unix系。すでにあるフォルダの権限は変えない）。デモは、一時フォルダのみを使い、本物の置き場所に触れない。
- CSVの書き出しは、文字列の欄の式の実行を防ぐ処理を入れる（先頭が `=` `+` `-` `@`、タブ、CRのとき `'` を足す）。表計算ソフトでの実際の挙動は、試験で確かめる。
- DB本体、`-wal`、`-shm`、バックアップは同じ権限（0600）。
- 脆弱性の報告は[SECURITY.md](../../SECURITY.md)。

## 速さ（目標。測定の方法と結果は `docs/benchmarks.md`）

| 項目 | 目標 | 条件 |
|---|---|---|
| ホームのまとめの応答 | 50ミリ秒以内 | 1万件の仕訳 |
| 台帳の起動時の検証 | 1秒以内 | 10万イベント |
| 仕訳の追記（1件） | 20ミリ秒以内 | 10万イベントの台帳 |
| 画面の操作の応答 | 100ミリ秒以内 | 未確認200行の一覧で、科目を打って候補を絞る |
| CSVの取込 | 1000件を1秒以内 | 合成データ |

## 見やすさ（WCAG 2.1 AA）

- 文字と背景は4.5:1以上、大きな文字と入力欄の枠、フォーカスの輪は3:1以上（ライトとダークの両方）。`tools` の試験が、色の定義から計算して確かめる。
- 色だけで意味を伝えない。赤字は文字で、状態（確定候補・取消済み・重複）は文字か記号でも示す。
- キーボードだけで、すべての機能に届く。Tabの順は画面の並びと同じ。フォーカスの輪を消さない。
- 入力欄には、見えるラベルを付ける。エラーは入力欄のすぐ下に出し、`aria-describedby` で結ぶ。送信に失敗したら、最初の誤りへフォーカスを移す。
- 表は `<table>` と見出しセル（`scope`）で作る。並べ替えできる列には `aria-sort` を付ける。グラフには、同じ数字の表と要約文を付ける。
- `prefers-reduced-motion` で動きを止める。`prefers-color-scheme` に従い、手動でも切り替えられる。
- 押せる場所は、画面の幅が1024px未満のとき44×44px以上（文章の中のリンクを除く）。

## 対応する環境

- ブラウザ: 公開時点の最新のChrome、Safari、Firefox、Edge。
- OS: macOS、Windows、Linux。最小のRustは1.88。
- 幅: 390、768、1440pxで確かめる。表は、幅に合わせて列を畳み（カードの積み上げ、補助の列を2行目へ）、横に隠れる列や「…」で欠ける文字を作らない（AC-11.6）。横にスクロールしてよいのは、帳票の切替の帯のように、選択肢が並ぶ部品だけ。

## データの大きさ

個人事業主の1年を想定する。年に5,000仕訳、10年で5万仕訳（10万イベント）まで、上の速さの目標を守る。それ以上は、保証しない。

## 参加しやすさ

- ビルドの工程を持たない。画面のファイルは、そのまま編集して再読込で確かめられる（`--ui-dir`）。
- 画面の依存は0。外部ライブラリを同梱しない。グラフは自作のSVG。
- 1つのソースは、読み切れる大きさ（目安は300行）に分ける。
