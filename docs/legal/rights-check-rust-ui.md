# Rust仕訳帳プレビューの作成記録

2026-10-15、既存のkamokuの仕様と本人のRust化の依頼から、Codexが実装しました。
通常画面の色や文字の定義、既存APIと自動試験を引き継ぎ、検索・状態・通信・
DOM操作を新しいRust crateへ移しています。他社サービスや他の会計OSSの
コード・画面・文面は参照していません。

RustのブラウザAPIはweb-sysとwasm-bindgenを使います。公式のAPI・配布資料を
確認し、依存とlockに版を記録しました。これらのライセンスはMIT OR Apache-2.0
です。推移的な依存も、通常のcargo-denyとREUSEのCIで確認します。生成された
JavaScript接続コードとWASMは、ビルド時に作る配布物で、手書きの業務処理では
ありません。

試験ではデモと架空の取引だけを使います。認証URL・Cookie・サーバーログ・
トレース・録画をアップロードせず、画像と計測JSONだけを保存します。
会計処理、保存、税のルールは変更していません。商標、特許、専門家による確認の
残件は[従来の記録](rights-check.md)を引き継ぎ、この作業で新たな判断はしていません。
